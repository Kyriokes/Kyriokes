#### 🎮 AoE2 BO Coach *(2026)*
An open-source overlay for Age of Empires II: Definitive Edition that reads the screen with OCR, follows a build order step by step, adapts when the player deviates and tells you where to put each villager. It comes with a public web library to share build orders.

- Windows desktop app in C# .NET 10 and WPF: screen capture, Windows OCR and custom digit templates for the game HUD

- Fair play: it only reads the screen. It never reads game memory, injects code or sends inputs
- **Stack:** C# .NET 10 · WPF · WebAssembly · TypeScript · Next.js 16 · React 19 · Tailwind CSS · Supabase · PostgreSQL · Vercel
